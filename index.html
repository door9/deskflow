DeskFlow

DeskFlow is a personal Windows desktop app for planning a newsroom editor's recurring reporting work: daily and weekly tasks with checklists, an important-dates calendar, notes and contacts. It is used by its developer on their own PC and is not distributed or sold.

How DeskFlow uses Google Calendar

When the user signs in with their own Google account and grants the permission https://www.googleapis.com/auth/calendar.events, DeskFlow:

  • shows the events of the user's own calendar in DeskFlow's calendar screen and its D-day counter;
  • creates an event in that calendar when the user chooses “Google Calendar” as the place to save a new event;
  • changes the title, date, time or description of an event, or deletes it, only when the user does so in DeskFlow;
  • writes the note the user types for an event into that event's description.

DeskFlow touches nothing else in the Google account. Calendar data stays on the user's PC; it is not sent to any server of ours, shared, sold, or used for advertising, analytics or AI training. Comments the user writes in DeskFlow are never sent to Google.

DeskFlow (한국어)

DeskFlow는 편집국 국장석의 반복 보고 업무(매일·매주 업무와 체크리스트), 중요 일정 캘린더, 메모와 연락처를 관리하는 개인용 Windows 앱입니다. 개발자 본인이 자기 PC에서만 쓰며, 배포하거나 판매하지 않습니다.

사용자가 본인 구글 계정으로 로그인해 calendar.events 권한을 허락하면, DeskFlow는 본인 캘린더의 일정을 앱 안에 보여 주고, 사용자가 앱에서 직접 만들거나 고치거나 지운 일정과 일정 메모(설명란)만 그 캘린더에 반영합니다. 그 밖의 구글 계정 정보에는 접근하지 않으며, 캘린더 자료를 다른 곳에 보내거나 공유하지 않습니다.
