DeskFlow

DeskFlow는 한 사람이 자기 Windows PC에서만 쓰는 개인용 업무 일정·기록 앱입니다. 일반에 배포하거나 판매하지 않습니다.

구글 캘린더 연동을 켜면, 사용자가 직접 로그인한 본인 구글 캘린더의 일정을 앱 안에 보여 주고, 사용자가 앱에서 직접 만들거나 고친 일정만 그 캘린더에 기록합니다.

  • 개인정보처리방침 (Privacy Policy)

DeskFlow is a personal desktop app used by its owner only; it is not distributed. With Google Calendar connected, it shows the signed-in user's own calendar events and writes only the changes the user makes in the app.
