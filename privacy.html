DeskFlow 개인정보처리방침

시행일 2026년 10월 1일

1. 앱과 사용자

DeskFlow는 한 사람이 자기 Windows PC에서만 쓰는 개인용 앱입니다. 일반에 배포하지 않으며, 다른 사람의 정보를 모으지 않습니다.

2. 구글 사용자 데이터에 접근하는 범위

구글 캘린더 연동을 켜면 사용자가 직접 로그인해 허락한 범위 https://www.googleapis.com/auth/calendar.events로, 사용자 본인 캘린더 일정의 제목·날짜·시간·설명을 읽고, 사용자가 앱에서 직접 만들거나 고치거나 지운 일정만 그 캘린더에 반영합니다. 다른 구글 서비스나 연락처, 메일 등에는 접근하지 않습니다.

3. 저장과 보관

  • 받아 온 일정과 앱에서 쓴 메모·댓글은 사용자의 PC에 저장됩니다.
  • 사용자가 원할 때에만, 앱의 자료를 암호화해 사용자 본인의 Dropbox에 동기화·백업합니다.
  • 구글 로그인 정보는 사용자 PC의 운영체제 보안 저장소에 암호화해 보관합니다.

4. 공유하지 않음

구글 사용자 데이터를 제3자에게 넘기거나 팔지 않으며, 광고·분석·인공지능 학습에 쓰지 않습니다. DeskFlow의 구글 API 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

5. 연결 해제와 삭제

앱의 설정에서 '로그아웃'하면 구글 접근 권한이 취소됩니다. 구글 계정의 서드 파티 연결 페이지에서도 언제든 권한을 취소할 수 있습니다. PC에 저장된 자료는 사용자가 앱의 자료 폴더를 지워 삭제할 수 있습니다.

6. 변경

이 방침이 바뀌면 이 페이지를 고치고 시행일을 새로 적습니다.

English summary: DeskFlow is a personal app used only by its owner on their own PC. With the user's consent (scope calendar.events) it reads the user's own calendar events and writes only the changes the user makes in the app. Data stays on the user's PC (optionally synced, encrypted, to the user's own Dropbox). Google user data is never shared, sold, or used for ads, analytics, or AI training, and its use follows the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked in the app or at myaccount.google.com/permissions.
