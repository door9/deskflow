DeskFlow Privacy Policy

Effective October 1, 2026

1. Who uses DeskFlow

DeskFlow is a personal Windows desktop app used by its developer on their own PC. It is not distributed, and it does not collect information about anyone else.

2. Google user data DeskFlow accesses

With the user's consent, given when they sign in with their own Google account, DeskFlow uses the scope https://www.googleapis.com/auth/calendar.events to read the title, date, time and description of events in the user's own calendar, and to create, change or delete events only when the user does so in the app (including saving the note the user types for an event into its description). DeskFlow does not access any other Google service or data.

3. How the data is used

The data is used only to show the user's events in DeskFlow (calendar screen, upcoming list, D-day counter) and to carry out the changes the user makes. It is not used for advertising, analytics, profiling, or to develop or train AI/ML models.

4. Storage and protection

  • Events and the notes and comments written in DeskFlow are stored on the user's PC.
  • Only if the user turns it on, DeskFlow's data is encrypted on the PC (AES-256-GCM) and synced or backed up to the user's own Dropbox. No one else can read it.
  • The Google sign-in token is kept encrypted with the operating system's secure storage (Windows DPAPI) on the user's PC.

5. Sharing

DeskFlow does not sell, share or transfer Google user data to any third party, and it has no server of its own that receives the data.

DeskFlow's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

6. Revoking access and deleting data

The user can sign out in DeskFlow's settings, which revokes DeskFlow's access, or remove DeskFlow at any time at myaccount.google.com/permissions. Data on the PC is deleted by removing DeskFlow's data folder; data in the user's Dropbox is deleted from the user's own Dropbox.

7. Changes

If this policy changes, this page is updated and the effective date above is changed.
